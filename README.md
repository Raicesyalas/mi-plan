# Mi Plan

App web familiar (se instala en el celular) para seguir el plan alimenticio de Noel, Ninoska y Stefanie: comidas del día, suplementos, agua, actividad, sueño, ánimo, libro de recetas con fotos, lista del súper compartida e historial.

- Usuarios y datos: Firebase (proyecto `mi-plan-b9b8a`). Las reglas de seguridad están en `firestore.rules`.
- Fotos de referencia de las recetas: Wikimedia Commons.
- Publicada con GitHub Pages desde la rama `main`.
